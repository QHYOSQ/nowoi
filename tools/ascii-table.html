About ASCII

ASCII (American Standard Code for Information Interchange) is a character encoding standard. This table shows decimal (0-255), hexadecimal, octal, and binary representations.

ASCII Table Guide

The ASCII table contains all standard characters used in computing. Control characters (0-31) are non-printable, printable characters (32-126) include letters, numbers, and symbols, and extended ASCII (127-255) contains additional characters.
